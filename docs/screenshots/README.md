# Screenshots

Drop a screenshot of the running dashboard here as `dashboard.png` - the main README links to
it at `docs/screenshots/dashboard.png`.

To capture one: start both servers (`mvn spring-boot:run` in `backend/`, `npm run dev` in
`frontend/`), open `http://localhost:5173`, run through an upload → job description →
screening flow so the shortlist has real data in it, then screenshot the page.
